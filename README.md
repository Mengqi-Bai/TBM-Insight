# TBM Insight

面向 TBM 施工现场的工程分析与科研平台。

- 施工进度、掘进工况、换刀统计和规范案例
- 支持真实数据、科研协作、试验、论文写作和图表

Windows x64 用户可解压便携包并双击「启动 TBM Insight」。在左下角「设置 → 工程数据」填写本机数据路径。工程看板可直接查询，使用对话和科研功能时在「设置 → 模型」配置模型服务。
