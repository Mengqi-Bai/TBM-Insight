# TBM 工程图

1. 先确定读者、工程问题和显示场景。明确读者看完要做什么，例如查某日准确值、比较刀位、判断运行走势或定位需要复核的时段。决定哪些信息需要一眼读出，哪些可通过游标、明细表或来源记录查到。
2. 核对查询时段、实测首末、样本、单位和缺测口径，保留来源行号。未知单位写明待确认。进尺用新增掘进估算，桩号实测位置单独标注。停机和工况用时占比沿用工具的联合 PLC 信号规则。
3. 根据读图任务选主图。比较不同日期或类别用对齐的条形图，查看累计变化或运行过程用折线图，定位超限用同时刻实测与 PLC 设定的叠图，核对大量精确数值用明细表。辅助图应回答另一个相关问题。多指标时序图共享现场时间轴，各指标用独立纵轴。
4. 根据实际密度决定标注。少量日期、类别或关键节点需要直接读数时，把数值放在对应柱端或点旁。PLC 秒级曲线等密集时序优先读走势，按问题标出峰值、设定变化或重要事件，详细读数用 Web 游标或明细。精度与单位、来源及任务匹配；清楚区分实测、估算、有效零值和缺测。缺测断线，压缩保留连续段首末、峰谷及断点。
5. 使用共享绘图模块和样式配置。会话用工具返回的 PNG，报告用 HTML，Web 保留游标与缩放。按实际显示宽度试读一次，能否快速定位目标、读准数值并理解单位和分母。检查标注与柱、点、线、图例是否一一对应且不遮挡。先调整位置或留白；仍拥挤时保留最有用的标注，把其余读数交给明细。检查字体、四边框、对齐、证据和空记录状态。

图型、数据字段和复现命令见 [绘图参考](references/figures.md)。

静态图的图例优先放在图内右上角。若与曲线、数据点、色块或标注重叠，依次检查左上、左下和右下。四角都没有空位时使用图框右侧留白。

## 选择图幅与对齐

- 独立图先按最终版面、数据密度、刻度和文字长度选择长宽。散点、ROC 和相关矩阵可从接近方形的图幅起步，密集时序优先加宽，排名或长类别名可优先增加高度。投稿图优先用期刊给出的栏宽。按最终显示尺寸检查字体、留白和标签。
- 需要上下对照的同日图，统一画布宽度、绘图区左右边界、时间范围和主刻度。全天按现场 00:00 至 24:00，缺测位置照常留空。可按测点数调整每张图的高度，涉及不同物理量的纵轴分别标注。
- 同一周的日进尺、停机和换刀事件等按同一组日期对齐，每个日期占用等宽位置。自然周用周一至周日。跨周比较且每周只汇成一个点或一根柱时，按周汇总图自身的标签和版面择宽。
- 在科研 Matplotlib 代码中用 `figsize=(宽, 高)` 指定独立图尺寸。绘制同一时间窗的对照图时，可用 `tbm_figure.new_figure(height, align_time=True)`，并共用时间范围与刻度。最后核对同一时刻或日期在组内的水平位置一致。

## 科研论文图

由写作助手或主助手明确稿件语言，委派时一起传递。中文稿的图题、横纵轴、图例、图内说明及图注用中文，英文稿相应全部用英文。单位、通用缩写和模型原名按学科写法保留。颜色条、分组标签和小图标题一起核对。需要双语图时分别保存两个完整语言版本，期刊明确规定的双语图注可按模板编排。

用研究项目的真实数据或已保存的结果数组绘制 Matplotlib 图，调用 `research_run_python` 时传 `figure_language: zh` 或 `en`。导出沿用共享字体、无网格、黑色四边框和图例定位。检查最终生成的图，不先用旧图改图注代替重新出图。重绘优先复用已有数据与分析口径；只有图像时先定位原始绘图数据或脚本。再用 `research_present_figures` 把实际图片和同语种图注带到项目对话。
