# TBM 科技论文写作

## 先确定投稿口径

确认目标期刊、稿件类型、写作语言、当前版本和本轮交付范围。优先从期刊官网、作者中心或出版商获取最新的投稿须知与模板。可使用 `web_search` 查官方入口，使用 `web_fetch` 阅读，再保存链接、核对日期和关键规则。用户提供的期刊模板可以直接作为本轮版式依据。

分别记录正文、摘要、全文的篇幅范围，注明按字、词、字符还是版面计量，以及标题、图表、图注、参考文献和补充材料是否计入。将硬性要求和建议篇幅分别记录。正式起草前按主要论点和证据分配章节篇幅。若官方只能查到页数或未给字数，使用临时写作预算并注明口径待核；最终版面需要按期刊模板检查。草稿和返修稿均调用 `research_check_manuscript` 实测篇幅。该工具的 Markdown 计数口径须和期刊要求核对。

## 先组织论证，再写正文

用一句话写明本文主要回答的问题。将核心结论逐项关联到已核实的表图、试验记录和文献，保留最关键的证据，安排其首次出现的位置。默认使用适合工程研究的章节结构，按期刊与稿件类型调整。

| 部分 | 写什么 | 容易混入的内容 |
|---|---|---|
| 标题、摘要、关键词 | 标题对应对象与贡献。摘要交代问题、数据与核心方法、最能回答问题的定量结果及结论边界。中英文术语、数字和单位一致。 | 工作过程、未完成事项、无数据支撑的评价，以及挤占摘要的完整指标清单。 |
| 引言 | 从工程问题和已有研究出发，比较最接近的方法，说明尚未解决的问题，最后提出本文要回答什么。 | 教材式背景、按作者罗列文献、详细处理步骤和整组结果提前复述。 |
| 工程背景、数据与方法 | 说明数据来源、设备、样本与变量、单位、样本纳排、指标定义、时间切分、基线和评价指标。将可复现所必需的细节放在这里。 | 运行日志、脚本逐步操作，以及对结果原因或工程效果的提前解释。 |
| 结果 | 按研究问题展示证据。先写主要发现，再用数字和对应表图说明，交代样本和对照。保留重要的阴性结果或不确定性。 | 将表格每格重述、临时调试记录、首次出现的方法、超出数据的因果断言。 |
| 讨论 | 解释结果和已有研究的关系、替代解释、局限和适用条件。关联证据强度与工程意义。 | 完整重写结果、将指标相关性直接当成地质或故障因果、未经验证的普遍化。 |
| 结论 | 直接回答引言提出的问题，简要陈述已经验证的主要发现及适用范围。 | 新数据、新方法、运维建议清单、投稿备注和后续待办。 |

## 段落、图表和格式

- 学术正文以段落为基本单位。每段围绕一个判断，将证据、比较和解释串起来。摘要、方法解释、讨论和结论默认用连续段落。期刊明确要求的结构式摘要、编号结论、公式或表格可按模板保留。
- 将清洗流程写成可复现的方法段落，阈值多时整理成规范参数表。工作进度、任务清单、版本备注和审核记录放在独立项目记录里。重要局限写入讨论，与对应结论关联。
- 按期刊模板核对层级编号、中英文题名和图表题、表格形式、公式符号、单位、数字范围和引文体例。Markdown 用于会话审阅，投稿版本以期刊要求的文件格式和版面为准。
- 正文先引用图表，再安排图表位置。图题和图注写清对象、变量、单位、分组和必要统计口径。选择直接支持主要结论的关键图，用 `tbm-figure` 核对可读性，再调用 `research_present_figures` 在对话中展示实际图像与图注。原稿只有图名时先找真实产物，找不到时报告缺图。
- 作图任务明确传递稿件语言。中文稿检查图题、横纵轴、图例和图内说明的中文表达，英文稿检查这些部分的英文表达。仅修改正文图注无法更新图中标注，需要使用原绘图数据重新导出。图注可遵循期刊的双语要求。
- 报道实测数据时核对样本数、单位来源、切分和指标。在缺地质真值时将可掘性指标表述为机械响应或间接证据。单设备留一区间验证的结论按实际工程范围表述。

## 初稿、模拟同行评审、返修与再审

完整稿件先保存独立版本，用 `research_check_manuscript` 核查篇幅、章节、列表、稿内工作备注及图占位。按需要用 `research_delegate` 委派作者起草或用同行审稿角色独立阅读该稿和必要证据。审稿角色先获得稿件版本、期刊口径、必要表图和试验记录，再提出意见。

审稿按重要性记录问题、正文位置、证据和建议，至少检查创新主张、数据与验证设计是否支持结论、统计与单位、图表和引用。意见保存为模拟同行评审记录，与该稿件版本关联。返修逐条说明实际改动和位置、增补证据，或在证据不足时收窄主张。每次返修保存稿件新版本和对应回复。

对返修稿重跑篇幅与格式检查，按审稿意见核对改动，再核对新增或改动的引文。存在可解决的实质问题时继续迭代。需要补做正式试验、改变已确认的结论或缺关键资料时，把要决定的问题交给用户。只改一个章节、只审稿或只核对格式时，按用户指定的交付范围执行。

写作方法参考公开的学术写作技能，篇幅和格式依据目标期刊，审稿与返修采用逐条可追溯的做法。 [学术写作技能参考](https://github.com/sjkncs/academic-paper-skill/blob/main/SKILL.md) · [Engineering 作者指南](https://www.engineering.org.cn/engi/EN/guidelines) · [Springer Nature 同行评审指南](https://www.springernature.com/gp/authors/campaigns/how-to-peer-review-3) · [Nature Computational Science 返修说明](https://www.nature.com/articles/s43588-025-00931-5)
