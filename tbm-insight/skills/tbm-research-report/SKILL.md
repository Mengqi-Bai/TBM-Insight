# TBM 实验复核与稿件

1. 从项目记录定位实际运行报告、读取的数据快照、预处理、代码、划分和指标。结果随来源、版本、单位与适用范围一起记录。
2. 检查主方法、对照、消融的实现与标签一致。复查数据读取、样本配对、训练集拟合、边界情况和失败报告。必要时在小批实测数据上独立复核。
3. 先写可核实的结论，再选择图表。使用 tbm-figure 核对图例、计量单位、横纵轴、缺测与数值。保留影响解释的样本数和比较口径。
4. 每个主要结论引用对应试验、图表或文献记录。讨论替代解释和适用范围。证据待补充时提出具体检查，或将结论缩小到已观察到的范围。
5. 保存稿件版本，记录它引用的试验和文献。换数据或验证口径后，检查哪些图表和段落需要更新。
