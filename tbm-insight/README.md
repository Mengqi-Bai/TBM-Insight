# TBM Insight

TBM Insight 是面向 TBM 施工现场的工程分析助手。当前演示支持 CREC188 掘进工况查询、进尺与停机汇总、参数超限检查、换刀统计与重点刀位复盘，以及规范与施工案例证据检索。

## 启动

Windows x64 便携包解压后，双击 `启动 TBM Insight.cmd`，随后会打开本机浏览器。包内已提供 Node.js 和 Python，使用设置保存在本机用户目录。首次启动需要准备运行依赖。

从源码运行需要先安装项目依赖并构建 Web。运行需要 Node.js 24.9 或更新版本及 Python 3.10 或更新版本。

```powershell
python -m pip install -r .\tbm-insight\tools\requirements.txt
pwsh -File .\tbm-insight\start.ps1
```

如有多个 Node.js 或 Python 安装，可用 `-NodePath` 和 `-PythonPath` 指定。默认由系统分配空闲端口并自动打开本机浏览器。需要固定端口时可传 `-Port`。传 `-NoOpen` 可改用终端打印的地址手动打开。对话需要在模型设置中选择已配置的模型。使用远程模型时，问题和工程工具返回的文本摘要会进入模型请求。

## 工程数据

从左下角打开「设置 → 工程数据」，选择包含 PLC 按日归档 ZIP 的目录。换刀台账可选择文件夹，也可直接填写 XLSX 文件路径。选择文件夹时，平台优先使用其中的「刀具更换信息统计表.xlsx」。目录中存在多份无法区分的 Excel 时，填写台账的完整路径即可。

「规范与案例库」留空时，便携版默认使用随包提供的规范、PDF 原件、案例及离线索引。也可指定其他已建索引的知识库目录。保存后，看板和对话工具使用同一套数据源。

当前 PLC 解析器按 CREC188 的字段和归档结构读取。日包形式为 `CREC188_YYYYMMDD.zip`，其中包含同名 TXT。现场数据有自己的设备字段或归档格式时，需要适配读取器。未指定时段时，工况查询以最新现场记录为基准取最近 60 分钟，范围限于同一归档日。

模型服务的 API 凭据在「设置 → 模型」配置，工程数据设置单独保存在本机。

## Web 业务看板

从「新会话」下方进入业务页面。看板直接读取工程数据，无需配置模型。点「带入会话」会生成可编辑的草稿，配置模型后即可发送追问。

| 页面 | 常用操作 |
| --- | --- |
| 施工进度 | 看每日掘进、周内累计和工况时间分布，点柱子展开当天明细 |
| 掘进工况 | 对照同一时段的刀盘转速、扭矩和推进力，按需打开越限详情 |
| 设备与换刀 | 从刀位排行、原因分布和日期趋势进入对应台账记录 |
| 规范与案例 | 按地域和资料类型查找条款或案例，查看引用与适用范围 |
| 科研平台 | 新建独立科研项目，在对话中提交研究任务并查看阶段进度和成果 |

演示引松项目时，选用 CREC188 的 2016 年 7 月 18 日至 24 日。这一周可同时查看 PLC 日汇总与换刀台账。新增掘进沿用日报的前缘估算口径，桩号单位待确认。停机时长由 PLC 信号估算，资料缺失的时段单独标识。

日期选择器只列相应数据源中有记录的日期。施工进度的时间占比按有归档日期从零点到最后一次观测的时间计算，缺测或无法判定的间隔单独展示。全线进度比例需确认设计总量和桩号单位后计算。首次查询尚未准备的历史周会先显示已就绪的日期，其余日期在后台逐日计算。

工况按日保存派生索引，供同一天的不同时间窗复用。三条趋势共用一个现场时间游标。在任一曲线上向上滚动放大，向下滚动缩小，三条曲线会围绕鼠标所在时刻同步缩放。图上保留的原始样本标为实测，邻近采样点之间的读数标为估算，断线区间标为缺测。

可离线准备一段历史数据的日汇总、周报摘要、默认工况和按日索引。程序会复用与原始归档匹配的已完成结果。

```powershell
python -B -X utf8 tbm-insight/tools/tbm_progress_index.py --from 2016-07-18 --through 2016-07-24 --include-conditions
```

## 演示问法

- 查看引松 CREC188 在 2016 年 12 月 15 日 18:17 到 18:22 的掘进工况。
- 看最近 5 分钟的刀盘转速、扭矩和总推进力。
- 查看引松最近 10 分钟的主液压油箱温度。
- 今天掘进多少米，停了多久？
- 昨天 TBM 掘进了多少米？
- 2015 年 7 月 10 日掘进了多少米？
- 画出 2015 年 7 月 10 日的全天掘进进度。
- 今天有哪些参数超限？
- 昨晚 18:00 到 20:00 主液压油箱温度有没有超限？
- 检查 2016 年 12 月 15 日主液压油箱温度和齿轮油温度的预警情况。
- 汇总 2016 年 12 月 14 日的净进尺和累计停机时长。
- 统计 2016 年 7 月 18 日至 24 日的换刀记录，哪些刀位反复处理？
- 查看 2018 年 1 月 18 日的换刀情况。
- 查看 49 号刀位在 2016 年 7 月 18 日至 24 日的处理原因。
- 岩石 TBM 刀具安装螺栓有什么规范要求？
- 煤矿 TBM 遇到地质异常区有什么规范依据？
- 有相似的断层卡机处置案例吗？

第一条应返回 300 条记录，来源为 `CREC188_20161215.txt` 第 65180–65479 行。时间窗口包含开始时刻，排除结束时刻。

日报使用当天零点至最后一条现场记录的窗口。「今天」按最新现场记录日期查询，「昨天」按该日期的前一天查询。指定年月日时直接使用指定日期。只问进尺时默认随数字展示全天进度图，只问停机时显示停机指标和统计截止时间。新增掘进按当天稳定最远桩号相对基准的前缘变化估算，首末桩号差保存在详情中。桩号单位待确认。展开工具工作详情可查看判定依据和原始行号。

换刀复盘只读使用已配置台账的 Sheet1，默认查询台账最新有效日期及此前六天，并显示查询范围和台账截止日期。显式结束日期不包含在查询范围内。结果包括原始记录数、刀位处理次数、涉及刀位数、重点刀位、原因分布、两张 PNG 和 HTML 明细。处理次数按台账展开后的刀位计数，新刀采购量需要另外核对刀具状态和库存。

换刀验收问题中的 2016 年 7 月 18 日至 24 日应返回 52 条记录、53 次刀位处理、23 个刀位，49 号刀位出现 5 次。2018 年 1 月 18 日应返回 8 条记录、9 次处理、9 个刀位。

## 规范与施工案例

知识资料、索引和历史版本副本存于 `tbm-insight/knowledge`。独立 MCP 服务使用本地索引检索，支持按机型、工程领域、地域及日期等条件筛选。具体规范要求和相似案例问题调用检索；普通术语和纯 PLC 数据问题沿用相应回答或工程工具。

规范结果提供条号、适用范围和 PDF 链接。案例结果可打开中文表格并切换英文原文。默认召回使用双语概念 TF-IDF、SQLite FTS5 和规则重排。入库、重建及独立验收方法见 `knowledge/README.md`。
